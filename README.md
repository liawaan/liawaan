### 👨‍💻 Tentang Saya

Saya adalah mahasiswa **Teknik Informatika** (Semester 5) di **Universitas Esa Unggul** dengan fokus pada pengembangan aplikasi web *full-stack*, aplikasi *mobile*, dan integrasi kecerdasan buatan (AI). Saat ini saya menjabat sebagai **Team Leader** dalam program **ASAH Bootcamp by Dicoding & GoTo**, memimpin tim lintas jalur (*Full-Stack, Data Science, dan AI Engineering*) dalam merancang solusi digital berbasis AI untuk UMKM.

- 🔭 **Sedang dikerjakan:** Pengembangan *web profile* & asisten cerdas berbasis RAG + *Intent Classification* untuk **Afitria Socks** (Capstone Project) serta aplikasi *e-wallet* **FinPay**.
- 🌱 **Fokus eksplorasi:** Arsitektur *Full-Stack* modern, integrasi LLM/RAG, dan persiapan magang industri.
- 🎯 **Peran & Aktivitas:** Duta Kampus Universitas Esa Unggul | AI Full-Stack Lead.
- 🎸 **Di luar *coding*:** Bermain gitar akustik dan analisis data *game* (MLBB).
